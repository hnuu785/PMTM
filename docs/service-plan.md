# PMTM 서비스 기획안

## 1. 서비스 개요

PMTM은 AI 랩 작사 보조 서비스다. 사용자가 BPM을 입력하면 해당 박자감에 맞는 랩 가사를 생성한다.

초기 제품은 기능을 넓히지 않는다. MVP는 `BPM 입력 + LLM 선택 -> 랩 가사 생성` 흐름에 집중한다.

## 2. 문제 정의

랩 가사를 처음 쓰는 사용자는 비트의 BPM에 맞춰 어느 정도 길이와 밀도의 가사를 써야 하는지 감을 잡기 어렵다. 일반 AI 글쓰기 도구는 문장은 만들어도 박자감, 플로우, 라인 길이를 충분히 고려하지 못한다.

PMTM은 사용자가 BPM을 입력하고 사용할 LLM을 선택하면 바로 랩 가사 초안을 얻을 수 있게 한다.

## 3. 목표 사용자

1. 랩 가사를 처음 써보는 사용자
2. 비트는 있지만 가사 초안이 필요한 창작자
3. BPM에 맞는 라인 길이와 플로우 아이디어가 필요한 래퍼 지망생

초기 핵심 타깃은 복잡한 설정 없이 바로 가사를 생성하고 싶은 개인 창작자다.

## 4. 핵심 가치

- BPM 하나만 입력해도 랩 가사 초안을 만든다.
- 로컬 Qwen 또는 OpenAI 모델 중 선택할 수 있다.
- 입력 과정이 짧고 이해하기 쉽다.
- BPM에 맞는 라인 길이와 호흡을 고려한다.
- 생성 결과는 바로 복사하거나 다시 생성할 수 있다.

## 5. MVP 범위

### 5.1 입력

MVP의 필수 입력값은 BPM 하나다. 사용자는 생성에 사용할 LLM을 선택할 수 있다.

- BPM: 예시 `80`, `90`, `120`, `140`
- LLM: `qwen-local`, `openai`

초기에는 주제, 장르, 무드, 섹션 구조 같은 추가 입력을 받지 않는다. 제품이 복잡해지는 것을 막기 위해 BPM 기반 생성 경험을 먼저 검증한다.

### 5.2 출력

서비스는 BPM에 맞는 8마디 벌스를 생성한다.

### 5.3 기본 액션

MVP에서 제공하는 액션은 단순하게 유지한다.

- Generate: BPM 기반 가사 생성
- Copy: 생성된 가사 복사

## 6. 제외 범위

MVP에서는 아래 기능을 제외한다.

- 주제 입력
- 장르 선택
- 무드 선택
- 라임 분석
- 섹션별 재작성
- 가사 저장
- 로그인
- 결제
- 음원 생성
- 멜로디 생성
- 자체 모델 실시간 서빙

## 7. 주요 화면

### 7.1 BPM Generator

첫 화면이 곧 핵심 기능 화면이다.

구성:

- BPM 입력 필드
- LLM 선택 컨트롤
- Generate 버튼
- 생성 결과 영역
- Copy 버튼

별도의 랜딩 페이지나 복잡한 대시보드는 만들지 않는다.

## 8. 사용자 흐름

1. 사용자가 BPM을 입력한다.
2. 사용자가 LLM을 선택한다.
3. `Generate` 버튼을 누른다.
4. 서비스가 BPM에 맞는 랩 가사를 생성한다.
5. 사용자는 결과를 복사하거나 같은 BPM으로 다시 생성한다.

## 9. API 초안

### 9.1 가사 생성

`POST /api/v1/lyrics/generate`

입력:

- bpm
- llm

출력:

- title
- lyrics
- bpm
- notes

예시 요청:

```json
{
  "bpm": 90,
  "llm": "qwen-local"
}
```

예시 응답:

```json
{
  "title": "90 BPM Demo",
  "bpm": 90,
  "llm": "qwen-local",
  "lyrics": "[Verse]\n...",
  "notes": ["Qwen/Qwen2.5-3B-Instruct 베이스 모델 생성 결과입니다."]
}
```

## 10. 기술 전략

초기 기본값은 순수 `Qwen/Qwen2.5-3B-Instruct` 베이스 모델이다. 사용자는 OpenAI 모델도 선택할 수 있다.

1. FastAPI에서 BPM 기반 생성 API를 만든다.
2. Next.js에서 BPM 입력과 결과 출력 화면을 만든다.
3. 백엔드는 `pmtm-ai`의 Qwen 추론 CLI를 호출한다.
4. OpenAI 선택 시 Responses API를 호출한다.
5. `pmtm-ai`의 학습/라임 자산은 후속 단계에서 품질 개선용으로 활용한다.

## 11. 1차 개발 로드맵

### Phase 1. BPM 생성 MVP

- 백엔드 요청 스키마를 BPM 중심으로 단순화
- LLM 선택값을 요청 스키마에 추가
- 순수 Qwen 기반 8마디 가사 생성
- OpenAI 기반 8마디 가사 생성
- 프론트 BPM 입력 UI 구현
- 프론트 LLM 선택 UI 구현
- 생성 결과 표시
- Copy 버튼 구현

### Phase 2. Qwen 생성 품질 개선

- BPM별 프롬프트 템플릿 작성
- BPM 기반 랩 가사 생성 규칙 반영

### Phase 3. 품질 개선

- BPM 구간별 라인 길이 조정
- 랩 스타일 샘플 프롬프트 개선
- 반복 생성 결과 비교

## 12. 성공 기준

MVP의 성공 기준은 아래와 같다.

- 사용자가 BPM을 입력하고 LLM을 선택해 가사를 생성할 수 있다.
- 입력부터 결과 확인까지 10초 안에 끝난다.
- 생성 결과가 랩 가사 형식을 가진다.
- BPM에 따라 라인 길이와 호흡이 다르게 느껴진다.

## 13. 제품 포지셔닝

PMTM은 범용 AI 글쓰기 도구가 아니라 BPM 기반 AI 랩 작사 보조 서비스다. 초기 포지션은 “BPM만 넣으면 랩 가사 초안을 만들어주는 가장 단순한 도구”로 잡는다.
